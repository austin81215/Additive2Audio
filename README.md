A simple additive synth as a personal / resume project. Additive synths work by adding individual sine wave harmonics together as opposed to applying effects to a more complex wave like most synths. This is closer to how an organ works and is somewhat rare, so I think the world could use more of them. This is my second major attempt at the project, this time using a more heavy duty audio programming setup (JUCE). Currently it's a standalone app, but I plan to eventually make it a plugin. Written and tested on Linux, should work on other platforms but do so at your own risk.
